How it works

  1. Upload a document (PDF or image)
  2. Optionally provide the target web form URL
  3. OCR extracts text from your document
  4. AI extracts structured data fields
  5. If a URL was provided, form fields are mapped
  6. Review and correct data in the review page
  7. Approve to auto-fill the web form
